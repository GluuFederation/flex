# Helm values reference

Every value the Gluu Flex Helm charts accept, with its type, default and description,
read from each chart's own `values.yaml`.

Pick the options you need and copy out a minimal override file and the install command that
uses it.

[Browse the values reference](https://gluu.org/docs/flex/reference/helm-values).

The same values are published with each chart: the
[`gluu` chart reference](https://github.com/GluuFederation/flex/blob/vreplace-flex-version/charts/gluu/README.md)
and the
[`gluu-all-in-one` chart reference](https://github.com/GluuFederation/flex/blob/vreplace-flex-version/charts/gluu-all-in-one/README.md),
or browse them on [Artifact Hub](https://artifacthub.io/packages/helm/gluu/gluu).
